# pankaj-labs

Pankaj Kumar's personal site: free AI tools (Job Application Tailor, Work-Visa Fit Report), side projects, and essays on AI agents, LLM engineering and governance.

These pages used to live on nordneuron.com, which now focuses on freight and supply-chain AI. nordneuron.com redirects the old URLs here, so paths (`/labs/...`, `/insights/...`) are kept identical.

## Run

```bash
npm install
npm run dev
```

## Environment

- `GEMINI_API_KEY` for `/api/job-tailor` and `/api/visa-report`.
